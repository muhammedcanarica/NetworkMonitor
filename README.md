# Network Monitor

A web-based network monitoring platform built with ASP.NET Core and React.

## Tech Stack

- ASP.NET Core Web API
- C#
- React
- TypeScript
- Vite

## Planned Features

- Device monitoring
- ICMP ping checks
- Latency monitoring
- Device status history
- Incident tracking
- Realtime dashboard
- Network discovery
- SNMP monitoring
- Interface and bandwidth monitoring
- Network topology
