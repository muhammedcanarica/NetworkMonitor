# Screenshot capture guide

Only capture NetScope with synthetic data or devices in an explicitly authorized lab. Before saving an image, remove or blur real IP addresses, hostnames, usernames, communities, credentials, email addresses, browser autofill suggestions, and company names.

Recommended desktop size is 1440x900; also verify one mobile-width view near 390px. Keep the same sample device names and neutral test data across images.

Capture these files when suitable real UI states are available:

| File | View | State to show |
| --- | --- | --- |
| `overview.png` | Overview | Mixed sample status and recent history |
| `device-detail.png` | Device Detail | Device Intelligence without secret fields |
| `topology.png` | Topology | Small authorized lab graph and legend |
| `incidents.png` | Incidents | Open and resolved sample incidents |
| `interface-traffic.png` | Interface Traffic | A collected baseline, chart, and threshold |
| `notification-center.png` | Notification Center | Unread badge and open drawer |

Do not manufacture screenshots. Until the real files exist, keep the text placeholders in the root README.
